🍁 Maple {{ VERSION }}

A secure JavaScript interpreter

Maple runs a script itself instead of handing it to eval, so the script only ever sees the values you pass in. Use it to let users write rules, formulas or automations that run inside your application without reaching anything else.

How it works

  1. 1

    Parse. acorn turns the script into a syntax tree, which the AST tab shows.

  2. 2

    Interpret. Maple walks that tree node by node. Nothing is ever handed to eval or Function.

  3. 3

    Isolate. The only names a script can reach are the ones the host passes in. Everything else, from Math to Array, is Maple's own.

What a script can't do

  • ✕ Reach host globals such as window, fetch or process
  • ✕ Turn strings into code with eval or Function
  • ✕ Climb prototypes through constructor or __proto__
  • ✕ Touch the DOM, storage, cookies or the network

Reading the playground

Host context
Trusted code standing in for your application. It runs natively and exports INSTANCE_DATA, read-only and shared by every run, and RUN_DATA, copied into each run.
Script
The untrusted code Maple runs. It sees the keys of those two exports and nothing else, and hands back its result with return.
Output
The result or the error, the syntax tree, and a benchmark against another interpreter. It updates as you type.
